# 💙 GenAI – Talk Freely. Feel Heard.

A modern **Mental Wellness Web Application** developed using **HTML, CSS, and JavaScript** to provide users with a safe, supportive, and user-friendly space for expressing emotions, tracking moods, practicing gratitude, and exploring simple wellness activities.

---

# 📖 About the Project

GenAI is a frontend-based Mental Wellness Web Application developed as a **B.Tech Web Development Project**. The objective of this project is to promote emotional well-being by providing users with a simple, interactive, and calming digital platform.

The application enables users to select their mood, engage in supportive conversations, maintain a gratitude journal, monitor emotional progress, access self-care tips, and explore wellness activities through an intuitive interface.

This project demonstrates the practical implementation of **HTML, CSS, JavaScript, DOM Manipulation, Event Handling, Responsive Web Design, and Browser Local Storage** while addressing a meaningful real-world problem.

3. Open `index.html` in any modern web browser.
4. Explore the features of the application.

No additional software or dependencies are required.
